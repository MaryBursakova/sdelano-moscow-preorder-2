# Сделано в Москве — Telegram Preorder MVP

Первая рабочая демо-версия предзаказа для кофейни в Сокольниках.

## Что уже работает

- гостевое меню с карточками товаров;
- фильтры по категориям;
- остатки и `нет в наличии`;
- корзина;
- оформление заказа;
- автоматическое уменьшение доступного остатка;
- номер заказа вида `A-127`;
- экран бариста;
- `−5 / −1 / +1 / +5 / Установить / Нет в наличии`;
- статусы заказов: Новый → Готовится → Готов → Выдан.

## Как посмотреть

Откройте `index.html` — экран гостя.  
Откройте `admin.html` — экран бариста.

Для демо оба экрана используют `localStorage` браузера. Если открыть их в двух вкладках одного браузера, изменения остатков и заказы будут видны сразу.

## Важно

Это именно MVP интерфейса и логики. Чтобы гости на своих телефонах и бариста на отдельном устройстве видели общие данные, следующим шагом подключаем сервер и базу данных.

## Цены

Часть кофейных цен пока стоит как демо-значение. Перед реальным запуском заменим их на фактические текущие цены.

## Деплой
